How This Tool Works

This tool reads your text line by line and keeps only the first occurrence of each unique line, removing any lines that repeat later in the list. Case-insensitive matching treats "Apple" and "apple" as the same line. Trim whitespace ignores leading and trailing spaces when comparing (so "apple " and "apple" count as duplicates). Remove empty lines strips blank lines from the result entirely. Sort alphabetically arranges the final, de-duplicated list in A-to-Z order.

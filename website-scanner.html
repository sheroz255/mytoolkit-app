How the MyToolkit Website Scanner Works

The MyToolkit Website Scanner is an online site inspection tool built entirely with native web technologies. Unlike traditional web scanners that send your code or domain requests to slow third-party proxies, this tool performs comprehensive client-side analysis directly in your browser.

When analyzing domain infrastructure, the scanner leverages DNS-over-HTTPS (DoH) to verify DNS record health across authoritative global resolvers. It validates IPv4 dual-stack routing (A and AAAA records), mail authentication standards (SPF and DMARC policies to prevent domain phishing), nameserver redundancy, and Certificate Authority Authorization (CAA) flags.

When analyzing page markup, the scanner feeds the HTML into the browser's native DOMParser. This runs an exhaustive, standards-based inspection across more than 40 essential indicators—including metadata hygiene, Open Graph protocol readiness, semantic heading nesting, web accessibility standards, resource hints, and secure coding practices.

The 5 Core Pillars of a Complete Website Audit

1. On-Page Search Engine Optimization (SEO)

  • Title Tag Optimization: Verifies the presence and length of the <title> element (optimal range: 30–60 characters).
  • Meta Descriptions: Checks for informative summaries (120–160 characters).
  • Canonical Link Tag: Confirms the presence of an absolute canonical URL.
  • Meta Robots Directives: Inspects indexability flags such as noindex or nofollow.
  • H1 & Semantic Headings: Validates proper heading hierarchy.

2. Security Posture & Domain Hygiene

  • HTTPS Protocol: Confirms encrypted TLS/SSL traffic.
  • Email Authentication (SPF & DMARC): Discovers DNS TXT records for Sender Policy Framework and DMARC.
  • Certificate Authority Authorization (CAA): Checks SSL certificate issuance restrictions.
  • Reverse Tabnabbing Protection: Audits external links with target="_blank".
  • Mixed Content Safeguards: Flags insecure http:// links and assets.

3. Digital Accessibility (WCAG Compliance)

  • Image Alternative Text (alt): Flags every <img> element missing an alt attribute.
  • HTML Language Attribute: Ensures the root <html> element declares a valid lang code.
  • Form Controls & Labels: Inspects input fields for corresponding <label> or aria-label tags.
  • Responsive Viewport: Checks for the modern mobile viewport tag.

4. Performance Signals & Clean Markup

  • Resource Hints: Inspects <link rel="preconnect"> and <link rel="preload"> tags.
  • Native Image Lazy Loading: Encourages modern loading="lazy" attributes.
  • DOM Tree Size: Calculates total element count to safeguard against DOM bloat.
  • Obsolete Elements: Flags deprecated presentational tags.

5. Social Media & Open Graph Protocol

  • Open Graph Core Tags: og:title, og:description, og:image, and og:url.
  • Twitter / X Card Metadata: twitter:card and corresponding image tags.

Understanding Browser Cross-Origin (CORS) Boundaries

When you enter an external URL in a browser-based tool, you might wonder why the tool cannot always fetch the full HTML directly. This is due to the browser's Same-Origin Policy (CORS). This security safeguard prevents arbitrary scripts on one website from reading private data from another website without explicit permission.

Instead of faking results or secretly routing your traffic through unvetted third-party proxy servers, MyToolkit maintains complete transparency:

  1. For any live domain, the tool queries public DNS-over-HTTPS endpoints to provide instant, genuine DNS and security record audits.
  2. For complete on-page audits, simply view the page source in your browser (press Ctrl+U or Cmd+Option+U), copy the HTML, and paste it into the Paste HTML tab.
  3. Our tool also provides direct, pre-configured links to official external diagnostic engines like Google PageSpeed Insights, Qualys SSL Labs, and SecurityHeaders.com.

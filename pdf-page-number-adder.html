How It Works

After you upload a PDF, choose where the page number should appear, which format to use, and what number to start counting from. The live preview updates automatically and shows a real render of the actual page with the number applied — not an approximation — so you know exactly what you'll get. If your document has a cover page that shouldn't be numbered, turn on "Skip first page"; the page count still includes it, but no number is printed on it. Once everything looks right, click "Add Page Numbers & Download" to apply the numbering to every page and save a new PDF file. The original page content is never altered — the number is simply drawn on top of each page.

How It Works

After you upload a PDF, the tool reads the document information stored inside it and fills in the form. Change any field you like, then click "Download Edited PDF". The tool writes your values into a copy of the file and downloads that copy. The original file on your device is never changed. If you click "Reset Fields", the form goes back to the values stored in the file. "Clear All Fields" empties the form so the downloaded file will have blank values for those fields.

100% private

What You Can Edit

A PDF stores basic descriptive information in a section called the document information dictionary. This tool lets you edit six of those fields: Title, Author, Subject, Keywords, Creator and Producer. Creation and modification dates and the page count are shown for reference. Changing a field does not change the pages, text, images or formatting of the document. If you change at least one field, the modification date is set to the current time, because the file has been changed.

Limitations to Know About

This tool edits the standard document information fields. Some PDFs also contain an XMP metadata block, which stores similar information in a different format. This tool does not edit that block, so some software may still show the old values. Documents can also contain comments, form field data, annotations or hidden text that are not part of these six fields. If a file must be fully scrubbed before sharing, check it in a PDF editor that can remove those items. Password-protected PDFs cannot be opened here.

Tips for Best Results

Use clear, consistent titles across related files, such as "Q3 Sales Report 2026", so they sort and search well. Separate keywords with commas, for example "invoice, 2026, client name". Once you download the edited copy, open it in a PDF reader and check the title shown in the window bar to confirm the change. Keep the original file as a backup until you have checked the copy.
